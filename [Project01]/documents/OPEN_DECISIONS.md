## 검토 결과

- **기획의 중심은 일관된다.** 한 사람의 물리적 왼손·오른손에 서로 다른 색 공이 올라와 있는지 판정하고, 제시 공 2개와 출발 영역에 남은 공 1개가 실제 프레임에 관측될 때만 정답으로 인정한다. Kalman 예측을 채점에 쓰지 않는다는 제한도 기획서와 규칙서에 일치한다.
- **수업 프로젝트 주제와의 연결은 확인된다.** `../../02_Computer-Vision.ipynb`의 Section Project 설명은 이미지 조정·색공간 변환·Image Enhancement·필터링·색상 분할·외곽선 검출·객체 추적·신체 인식 및 신체와 객체 관계의 표현을 요구한다. 계획서는 각 기술의 역할을 적었다. 색 마스크가 안정적으로 동작하면 CLAHE는 적용하지 않는 방향이며, 블러를 포함한 실제 처리 방식은 영상으로 확인해야 한다. 실제 장비 검증은 아직 없으므로 **모든 기술을 실제로 활용했다고 판단할 수 없다.**
- **사용자가 점수·기회 규칙을 구체화했다.** 성공 +1점, 완성된 제시 자세에서 안정적으로 확인된 오답 또는 시간 초과 시 기회 -1, 기회 0에서 종료다. 오답 판정 시간과 미완성 장면의 처리 방식은 오검출 방지를 위한 설계 제안이며 현장 시험이 필요하다.
- **기존 실습은 출발점일 뿐이다.** `../../2026.10.18/`에는 단일 초록 공 검출·추적과 손 인식 코드가 따로 있다. 3색 공과 두 손 위의 공 후보 판정, 상태 전이, 채점이 통합되어 동작한다는 증거는 없다.
- **평가 비중과 README 형식을 확인했다.** 제공된 채점표의 배점은 기술적 완성도·안정성 30%, 코드 구조·가독성 20%, 제출 형식·요구사항 10%, 창의적 설계·구현 30%, 시연·발표 10%다. 사용자가 제공한 README 형식에 맞춰 `파일 구조`와 `실행 방식`을 필수로 표시했다. 강사는 코드 작성 이유도 README에 적으면 좋겠다고 조언한 것으로 사용자에게 들었으며, 이는 채점표에 적힌 별도 필수 항목은 아니다.

## 코드 작성 전에 정할 구현 경계

2026-10-22 하네스 범위는 승인됨: Mac에서 Python 3.10.12·표준 라이브러리 `unittest`로 관측 계약과 테스트 도우미만 구현한다. 현재의 단순화된 구조는 [HARNESS_DESIGN.md](HARNESS_DESIGN.md), 현재 변경 순서와 검증 조건은 [HARNESS_IMPLEMENTATION_PLAN.md](HARNESS_IMPLEMENTATION_PLAN.md)를 따른다. Homebrew의 pyenv와 필요한 빌드 라이브러리 준비, 프로젝트 `.venv` 생성은 승인된 환경 작업이다. 전역 Python과 셸 시작 설정은 변경하지 않고 설치 실패 시 버전 대체 없이 중단·보고한다. 해당 결정은 재승인 대상이 아니다.

위 하네스 승인에 이어 2026-10-22 게임 구현 계획과 첫 단계(한 프레임 판정), 이후 사용자 요청에 따른 2단계(준비와 문제 시작)가 승인됐다. 정답·오답 누적·제한 시간·점수·장애·실제 카메라는 한 단계씩 설명·확인하며 진행한다. 하네스 검증은 실제 인식 정확도나 통합 게임 성공의 증거가 아니며 실제 실행 결과는 체크리스트에만 남긴다.

### MediaPipe 모델 확보 결정

사용자 제공 정보에 따르면 Jetson에는 아래 명령으로 손 모델과 포즈 모델이 이미 다운로드되어 있다. 이는 **사용자 보고**이며, 이 작업 환경에서 Jetson의 파일이나 실행 결과를 직접 확인한 것은 아니다. 현재 저장소에는 두 `.task` 파일이 없다.

```bash
pip install --no-deps mediapipe
pip install absl-py flatbuffers sounddevice
wget https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task -O src/models/MediaPipe/hand_landmarker.task
wget https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/latest/pose_landmarker_full.task -O src/models/MediaPipe/pose_landmarker_full.task
```

따라서 **모델 다운로드 방법과 Jetson 내 배치 경로는 결정됨**으로 처리한다. 경로의 `src/models/MediaPipe` 디렉터리는 다운로드 전에 존재해야 한다. 이 게임의 현재 판정에는 손 랜드마크만 필요하며, 포즈 모델은 다운로드되어 있다는 사실만 기록하고 사용 범위에는 넣지 않는다. Jetson에서 파일 존재·비어 있지 않은지·MediaPipe 손 모델 로딩과 실제 추론이 되는지는 별도 점검 항목이다.

## 실물 확인 전에는 확정할 수 없는 값
