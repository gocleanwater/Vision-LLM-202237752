## 2. 수정된 질문·선택 동작의 현장 확인

2026-11-08 로컬 리뷰에서 아래 문제를 수정하고 테스트했다. 현장에서는 실제 STT로 받은 문장에도 같은 동작이 이어지는지 확인한다.

- [ ] `냉장고에 있는 재료로 뭐 먹을까?`를 재료 조회가 아닌 메뉴 추천으로 처리한다.
- [ ] `메뉴 추천하지 마` 같은 부정 요청에는 촬영·추천하지 않는다.
- [ ] `둘 다 먹는 대신 카레 먹자`가 이전 두 메뉴를 기록하지 않는지 확인한다. 복합 문장이 불명확하면 저장을 보류하고 되묻는다.
- [ ] `주먹밥 먹자`, `먹물파스타 먹자`를 정상 메뉴 선택으로 처리한다.
- [ ] `마시멜로 먹자`에서 음식 이름의 `로`를 잘라내지 않는다.
- [ ] 표시·TTS가 계란·계란말이로 나오고, 달걀 표기의 입력·기존 기록도 같은 음식으로 비교하는지 확인한다.
- [ ] 기존 `그걸 먹자`, `아무 음식 먹자` 미저장과 `둘 다 먹자`의 함께 저장도 유지되는지 확인한다.

테스트 코드는 Git에서 제외되어 새 clone에는 없다. Mac 로컬에서는 위 사례를 포함한 구매 재료 조회를 포함해 68개 테스트가 통과했다. 현장 수정 후 테스트가 있는 개발 폴더에서도 검사하고 README·검증 기록을 갱신한다.

## 5. 카메라·마이크·스피커

- [ ] USB 카메라가 `/dev/video0`인지, 다른 프로그램이 사용 중인지 확인한다.
- [ ] OpenCV GStreamer 빌드와 `int8_yolo.py`의 카메라 파이프라인이 동작하는지 확인한다.
- [ ] `arecord -l`, `aplay -l`로 장치 번호를 확인한다. 기본 USB 마이크 `plughw:CARD=Microphone,DEV=0`과 다르면 `--mic-device`를 바꾼다.
- [ ] 한국어 한 발화가 녹음되고 Whisper가 인식하는지 확인한다.
- [ ] Piper 한국어 합성과 스피커 재생을 확인한다.
- [ ] RMS 시작값 500, 종료 무음 0.8초, 최대 발화 15초를 실제 환경에서 확인한다. 말이 잘리거나 소음에 시작하면 조정한다.
- [ ] TTS가 자기 응답을 다시 인식하지 않고, 응답 후 새 질문을 정상적으로 받는지 확인한다.

## 6. 단계별 연결과 실물 재료 선별

- [ ] 재료 조회부터 시험한다. 같은 재료 여러 개가 보여도 한국어 종류명만 한 번 안내해야 한다.
- [ ] 모든 상자가 확실하면 VLM 이미지 호출을 생략하는지 확인한다.
- [ ] 애매한 후보가 있는 사진으로 실제 콜라주가 전달되고 VLM 이미지 확인이 수행되는지 확인한다.
- [ ] VLM 실패 때 애매한 후보만 제외하고 확실한 재료는 유지하는지 확인한다.
- [ ] Gemma `n_ctx=2048`에 이미지와 JSON 출력이 들어가는지 확인한다. 오류가 나면 원인을 보고 문맥·출력 설정을 조정한다.
- [ ] 실물 또는 출력 사진을 놓고 잘 인식되는 재료 3~5종과 배치를 정한다. 출력 사진이면 시연에서도 사진이라고 설명한다.
- [ ] 메뉴가 실제 보유 재료를 활용하고, 빠진 재료는 추가 재료로 안내하는지 사람이 확인한다.

## 7. 전체 시연 순서

```bash
cd ~/vision-llm/'[Project02]'
python main.py
```

Gemma 환경이나 마이크가 다르면 확인한 값으로 옵션을 추가한다.

- [ ] “냉장고에 식재료 뭐뭐 있어?” → 종류만 안내.
- [ ] “오늘 뭐 먹을까?” → 최대 2개 메뉴와 필요한 추가 재료만 안내.
- [ ] “딴 메뉴 없어?” → 같은 이벤트에서 앞서 안내한 메뉴와 겹치지 않음.
- [ ] “카레가 먹고 싶어. 지금 사와야 하는 재료가 뭐야?” → 현재 재료를 새로 보고 부족한 종류만 안내. 식사 기록·기존 추천 문맥은 유지.
- [ ] 필요한 재료가 모두 관측되면 구매할 재료 없음 안내. 메뉴가 없으면 먼저 되묻기, 빈 관측은 인식 실패로 처리.
- [ ] “그래, ○○ 먹자” → 날짜와 선택 메뉴 저장. 추천 밖 메뉴도 허용.
- [ ] 새 추천 → 오늘·어제·그저께 선택 메뉴 제외.
- [ ] 마지막 추천이 1개인 경우와 2개인 경우에 “둘 다 먹자” → 해당 목록을 함께 기록.
- [ ] “좋아”, “그걸 먹자”, 부정·질문 표현 → 불명확한 선택은 저장하지 않음.
- [ ] `Ctrl+C` 종료·재실행 후 식사 기록이 유지되고 추천 이벤트 임시 목록은 초기화됨.
- [ ] 카메라·오디오 오류와 모델 지연 때 멈춤·자원 정리·재실행 동작을 확인한다.
