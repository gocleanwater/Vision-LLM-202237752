# 구현·검증 체크리스트

기준일: 2026-11-08. 사용자의 간단한 함수 중심 구성에 따라 초안의 여러 모듈을 `main.py`, `vision.py`, `gemma.py`, `speech.py`로 합쳤다.

## 코드와 로컬 검증

- [x] 음식 별칭, 메뉴 JSON 검증, 최근 메뉴·같은 응답 중복 제외, 정해진 한국어 출력 구현.
- [x] 여러 보유 재료와 추가 구매 재료를 분리하고 필요한 메뉴에만 추가 안내.
- [x] 한국 시간 오늘·어제·그저께 기록을 개수 제한 없이 사용하고 선택 때 원자적으로 저장.
- [x] 추천 전·추천 밖 선택 허용, 마지막 추천 모두 선택, 모호·부정 선택은 저장 보류.
- [x] 이벤트 동안 안내한 이름 전체를 제외하고 대안 요청에 같은 재료 재사용.
- [x] 재료 조회는 종류만 중복 없이 안내하고 식사 파일과 추천 문맥을 유지.
- [x] 노트북 STT/TTS·Gemma와 `int8_yolo.py`의 카메라·predict 호출을 재사용.
- [x] 확실한 YOLO 결과와 애매한 후보 분리, 후보 콜라주 한 장·VLM 한 번, 실패 시 확실한 재료 보존.
- [x] PCM 음량 기반 발화 시작·끝 감지 구현. 처리·TTS 중에는 녹음 프로세스를 열지 않음.
- [x] 로컬 규칙·외부 경계·오류 처리 테스트 68개 통과. 테스트는 가상 기록·임시 파일만 사용.
- [x] 네 Python 파일 문법, CLI 도움말, 테스트·캐시·모델·런타임 파일 Git 제외 확인.

- [x] 추천·조회 충돌, 부정 요청, 복합 모두 선택, 음식명 훼손과 긴 선택 입력을 회귀 테스트로 재현·수정하고 서브에이전트 재검토.

- [x] 지정 메뉴의 구매 재료 조회, 필요 재료·관측 차집합, 문맥·식사 기록 보존, 메뉴명 끝 이 보존을 14개 추가 테스트와 서브에이전트로 확인.

- [x] 표시·음성·새 기록을 계란 표기로 통일하고, 기존 달걀 기록 제외와 구매 재료 별칭을 추가 검사.
