# 구현 검증 기록

최종 검증일: 2026-11-08. Mac의 현재 작업 폴더에서 수행했다. 실제 Jetson 모델·장치 검증과 구분한다.

## 수행한 검사

| 검사 | 결과 | 범위 |
| --- | --- | --- |
| `.venv-ingredients/bin/python -m unittest discover -s '[Project02]/tests' -q -b` | 70개 통과 | Python 3.12.16, 카메라·마이크·실제 모델 없이 수행 |
| `python3 -m py_compile`로 네 소스 파일 검사 | 통과 | Python 문법 |
| CLI 도움말·음성 실행 루프 | 도움말 실행·모의 연결 통과 | 실행 옵션 유지, 입력·응답 연결과 종료 시 Gemma 정리 확인 |
| Git 제외 규칙과 추적 목록 | 확인 | 테스트·캐시·runtime·식사 기록·모델은 제외, 소스·문서는 포함 |
| 별도 코드 검토 | 지적 수정 후 회귀 검사 통과 | 가상환경 Python 심볼릭 링크 보존, 모호한 메뉴 선택 금지, 접두어가 있는 모두 선택 |

실패 주입 테스트의 오류 로그는 예상된 결과다. 테스트에서 실제 가족 기록을 만들거나 변경하지 않았다. `tests/`는 사용자의 요청에 따라 Git에서 제외하므로 이 기록만 원격 저장소에 남고, 새 clone에는 테스트 파일이 없다.

## 테스트에서 확인한 동작

- 최근 3일의 9개 기록을 모두 사용하고 이전 날짜 제외. 별칭·같은 응답 중복 정리.
- 유효 메뉴가 하나면 추가 생성 없이 안내. 구매 재료는 별도로 안내하고 보유 재료의 구매 중복 제거.
- 대안 추천은 이벤트 전체 안내 메뉴 제외, 촬영 재사용. 후보가 없거나 선택 저장이 성공하면 임시 문맥 삭제.
- 추천 밖·추천 전 메뉴 저장, 마지막 추천 1~2개 모두 저장. 저장 실패·손상 파일은 기존 기록 보존.
- `그걸 먹자`, `아무 음식 먹자` 같은 지시어·불특정 메뉴 표현은 되묻고 기록과 추천 문맥을 유지.
- 모호·부정·질문 형태와 `카레 아니면 잡채 먹자` 같은 미정 선택은 저장하지 않음.
- 재료 조회는 중복 없이 종류만 안내, 식사 파일에 접근하지 않고 추천 문맥 유지.
- 신뢰도 경계 분류, 여러 애매한 후보에 확인 호출 한 번, 없는 번호·중복 번호·미지원 재료 거절. VLM 실패 때 확실한 재료 보존.
- 생성한 색상 배열로 두 bbox가 한 콜라주에 포함되는지 확인. 실제 식재료 사진 인식 검사는 아님.
- 생성한 PCM 파형에서 한 발화만 추출, 짧은 소음 무시, 최대 길이 종료. 실제 사람 음성과 생활 소음 판별 정확도는 미검증.
- Whisper 호출 인수와 Piper 실패 시 이전 음성 미재생 검사. 실제 Whisper·Piper 실행은 아님.
- 작은 Python 응답 프로세스로 Gemma 통신의 재사용·종료·타임아웃 정리 확인. 실제 Gemma 추론 검사는 아님.

## 최종 코드 리뷰 후 회귀 검사

다섯 가지 기존 의도·메뉴명 오류를 재현한 뒤 수정했다. 추천·재료 조회 충돌, 추천 금지 표현, 복합 문장의 잘못된 모두 선택, `주먹밥`·`먹물파스타` 거절, `마시멜로` 잘림을 검사한다. `그래놀라` 보존, 한글 받침에 맞는 일부 조사 처리, 100자 초과 입력의 미저장도 확인했다.

수정 중 서브에이전트가 발견한 `대신에`, `싫어` 복합 선택 회귀도 실패 테스트로 재현하고 수정했다. 최종적으로 실행 환경 `.venv-ingredients`에서 테스트 **51개 통과, 스킵 0개**를 확인했고, 서브에이전트도 독립 실행으로 같은 결과를 확인했다. 테스트 파일은 계속 Git에서 제외한다.

음식 선택은 고정 음식 목록으로 제한하지 않는다. 다만 모르는 음식 이름 끝의 `로`와 조사를 일반적으로 구별할 수는 없어 원래 이름을 보존하는 쪽을 택했다. 등록된 패턴 밖의 자연어·별칭 처리를 완전히 보장하지 않는다.

## 구매 재료 조회 추가 검증

기존 51개에 구매 재료 조회 테스트 14개를 추가해 **65개 통과, 스킵 0개**를 확인했다. 원하는 메뉴의 전체 재료에서 새 관측을 빼는 처리, 등록된 한영 별칭·중복·미학습 이름, 전부 보유, 메뉴 누락, 다른 음식 응답·빈 목록·자료형 오류와 1회 보완, 관측 실패, 기존 손상 기록·추천 상태 불변을 검사했다. 일반 추천에 추가 재료 요청을 붙인 경우도 기존 분기로 유지한다.

서브에이전트가 발견한 `떡볶이`·`달걀말이`의 이름 끝 잘림을 실패 테스트로 재현해 수정했다. 서브에이전트도 최종 65개를 독립 실행해 같은 결과를 확인했다. 실제 Gemma가 요리의 필수 재료를 빠짐없이 제안하는지와 Jetson 음성 연동은 아직 검증하지 않았다.

## 계란 표기 선호 반영

표시·음성·새 기록에 계란 표기를 적용했다. 음식 이름·공백 별칭, 이전 달걀말이 기록의 추천 제외·파일 보존과 새 선택 저장, 달걀 재료 별칭의 보유 제외 테스트 3개를 추가했다. 기존 테스트의 표시 기대값을 갱신했고 총 **68개 통과, 스킵 0개**를 확인했다. 실제 개인 기록 파일은 변경하지 않았다.

## 노트북 중심 단순화 후 검사

기존 기능 테스트와 실제 작은 Python 작업자의 파일 통신으로 총 **70개 통과, 스킵 0개**를 확인했다. 같은 모델 프로세스의 요청 반복, 서로 다른 응답 수신, 오래된 응답 파일 삭제, 작성 중 임시 파일 미사용, 타임아웃 시 자식 프로세스 종료, 명시적 `close()`와 음성 루프 연결을 검사했다. array·math 음량 계산·발화 시작과 종료·최대 길이 테스트도 통과했다. 서브에이전트 검토에서 단일 실행·순차 요청 범위의 추가 차단 문제는 발견하지 못했다. 실제 Jetson 모델·장치 검증은 수행하지 않았다.

## 남은 확인

Jetson SSH가 연결되지 않아 이번 구현에서 실물 실행은 못 했다. 최종 엔진도 Project02 폴더에 배치하지 않았다. 카메라·오디오 명령·Gemma 환경, 실제 메뉴 타당성, 인식 정확도, 응답 지연·메모리는 검증하지 않았다.

YOLO 탐지 0.15 / 즉시 수용 0.65, RMS 500 / 종료 무음 0.8초 / 최대 발화 15초는 구현 시작값이다. 노트북과 같은 Gemma `n_ctx=2048`을 유지했으며 이미지·JSON 길이가 이를 넘는지 실물에서 확인해야 한다. 음식 별칭과 추가 재료 동의어는 등록된 범위만 처리한다.

Whisper·Piper·aplay는 120초, Gemma는 180초 제한이 있다. 카메라·YOLO 네이티브 호출의 강제 타임아웃은 아직 구현하지 않았다. 하네스 H01~H47의 모든 실물 조건이 통과했다고 해석하지 않는다.
